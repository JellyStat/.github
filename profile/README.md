## Jellystat

A free and open source statistics app for Jellyfin and Emby.

**→ Start at [JellyStat/Jellystat](https://github.com/JellyStat/Jellystat)** for install instructions, issues and discussions.

| Repository | What it is |
|---|---|
| [Jellystat](https://github.com/JellyStat/Jellystat) | Install docs, Docker Compose, issues and discussions |
| [JellyStat-API-Core](https://github.com/JellyStat/JellyStat-API-Core) | .NET backend API |
| [Jellystat-UI](https://github.com/JellyStat/Jellystat-UI) | Next.js web interface |

Want to help? Read the [contributing guide](https://github.com/JellyStat/.github/blob/main/CONTRIBUTING.md), or help [translate the UI](https://github.com/JellyStat/Jellystat-UI/blob/main/TRANSLATING.md).
