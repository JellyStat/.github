# Security policy

## Reporting a vulnerability

Please **don't** report security problems in a public issue or discussion.

Report them privately through GitHub instead: go to the [Security tab of the Jellystat repo](https://github.com/JellyStat/Jellystat/security/advisories/new) and click **Report a vulnerability**. Include:

- what the problem is and what an attacker could do with it;
- steps or a proof of concept to reproduce it;
- the Jellystat version you tested.

We'll acknowledge your report, keep you updated while we work on a fix, and credit you in the advisory unless you'd rather stay anonymous.

## Supported versions

Only the latest Jellystat release gets security fixes.
